What this experiment is

This is a tiny character-level neural language model with a trainable attention mechanism. It uses a learned query to attend to a window of earlier characters and predicts the next character. Training updates its embeddings, attention matrices and output layer with gradient descent.

Important: This is an educational attention model, not a complete multi-layer Transformer or a ChatGPT-like assistant. It is not pretrained on large text collections and will usually generate imperfect language. It cannot do general question answering or online research.

4. How the network works

The network reads the last 16 characters, maps them to 16-dimensional embeddings, computes a query for the newest character and keys for previous characters, and uses attention weights to combine their value vectors. A trainable output projection predicts the next character. This is one attention-based neural predictor, not an entire Transformer stack.

Training uses next-character examples drawn from the text box. More training may improve its ability to imitate the training data, but the model's tiny size, character-level vocabulary, and limited dataset prevent general reasoning. Downloaded models and external APIs are not used.
